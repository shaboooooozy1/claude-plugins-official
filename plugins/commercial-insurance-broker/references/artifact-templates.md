# Artifact Templates

Fill with stated facts only. Bracket `unverified` or missing items as
`[MISSING]`. Do not send as a licensed or issued document.

## Intake memo

```text
Account: [legal name] / DBA [ ]
Operations: [plain language]
Target effective: [date]
Lines in play: [ ]
Incumbent: [carrier / premium if stated]
Blocking gaps: [ ]
Later gaps: [ ]
Recommended next step: [workflow]
```

## Underwriter summary (submission)

```text
Subject: New submission — [named insured] — [lines] — [effective]
Operations and exposure base: [ ]
Controls: [ ]
Losses (valuation date): [ ]
Coverage intent: limits / AI / waiver / PNC
Markets: [list with appetite note]
Subjectivities expected: [ ]
```

## Bind order

```text
Please bind [carrier / option] effective [date].
Named insured: [exact spelling]
Premium / payment plan: [stated]
Subjectivities attached / outstanding: [owner]
Confirm: locations, vehicles, mortgagee/loss payee
```

## FNOL draft

```text
Date/time learned: [ ]
Date/time of loss: [ ]
Location: [ ]
Parties / injuries / property: [ ]
Policies that may respond: [numbers if stated]
Documents to collect: incident report, contracts, photos
Do not include coverage determinations.
```

## BOR letter body

```text
[Named insured] appoints [agency] as broker of record for [lines /
policy numbers if stated], effective [date]. Please recognize this
agency for servicing and renewal. Contact: [producer].
```

## Proposal outline

1. Executive recommendation
2. Account and coverage intent
3. Option matrix (from `quotes`)
4. Binding and payment
5. Subjectivities and timeline
6. Caveats and `unverified` items
7. Next action for the insured

```text
Holder: [ ]

Do not issue until: [endorsements / verification]
```
